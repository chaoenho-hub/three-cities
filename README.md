# 法國三城觀察 Three Cities Field Notes

青年百億海外圓夢基金計畫 M-4-5「藝起共築理想城市」見習田野工具的公開展示版。

- 觀點：三種尺度、五種城市意象、三個研究問題
- 路線：18 天站點與城市地圖
- 手冊：《文化驅動的都市再生：法國三城觀察》

見習期間的現場記錄會整理後同步到 `data/records.json` 與 `photos/`。
